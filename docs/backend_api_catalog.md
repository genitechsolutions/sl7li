# Backend API catalog (from the devqa web client, 2026-11-01)

Extracted from the site's public JS (all 63 routes' chunks) and a headless-browser run on the public pages. Keys are not recorded.

## Transport / auth
- GraphQL over HTTPS: `POST https://khlnguhv6jfa3l476zlirvz7ay.appsync-api.us-east-2.amazonaws.com/graphql` (devqa). Amplify JS v6.15.
- Signed-in calls use the Cognito user pool token (`authMode: userPool`). Guests: the site calls Cognito Identity (`GetId` / `GetCredentialsForIdentity`, no logins) and sends the AppSync API key header.
- Phone-number sign in (OTP via SMS; `resendOtpSecure` mutation). Uploads: `generateUploadUrlSecure` -> presigned S3 `PUT` -> then e.g. `submitGovernmentIdVerificationSecure(s3Key)`.
- Most `*Secure` mutations/queries take `input: AWSJSON` and return a JSON string (`{ error, job|proposal|professional|... }`) that the client `JSON.parse`s.
- Public static: `/content/products.json`; images/resources from `devqa-resources.salehli.com` (the browser run also fetched `resources.salehli.com` service images).
- Analytics: Amplitude, Meta pixel.
